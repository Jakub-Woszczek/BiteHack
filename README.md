## Shopico

Shopico is a functional e-commerce template built as a foundation for a modern online store.

It includes a product listing page with price-based sorting and category filtering, along with user authentication, account management, a wishlist system, and product search by name.

The project focuses on delivering a clean structure and scalable architecture suitable for further expansion.

**Backend:** Java \
